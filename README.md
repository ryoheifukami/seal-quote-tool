# シール堂印刷 見積り作成ツール（社員用）

シール・ラベル・ステッカーの条件（サイズ・素材・加工・数量・納期）を入力すると、
見積金額・原価・粗利がその場で計算され、**複数品目を積み上げてExcel見積書**を出力できる社員用ツールです。

> **料金・原価はすべて「仮」の設定です。**
> シール堂印刷さんの実際の単価表・原価が決まったら、`pricing.py` の数値を書き換えるだけで本番の見積りになります。
> （計算の流れはそのまま使えます。）

## できること

- サイズ・素材・加工・数量・納期から**見積り自動計算**（面積×数量で単価が決まる業界方式）
- **品名・材質はプルダウン**で選択。色味（フルカラー／単色×色数）・セットアップ（内職）にも対応
- **マスキングテープ系**は幅×長さで 仮 の概算（※シールと価格構造が別のため精度は粗い）
- **問い合わせ本文の貼り付け→自動反映**：フォームやメールの文面を貼ると、数量・サイズ・材質などを読み取って各項目に入れる
  - APIキー（`ANTHROPIC_API_KEY`）があれば **AI読み取り**、無ければ **パターン照合**（ラベル付きの依頼文はしっかり拾えます）
- **複数品目の積み上げ**（1つの見積書に何品目でも）
- **値引き**（金額／％）を入れると**粗利・粗利率が再計算**、原価割れは赤字警告
- **Excel見積書のダウンロード**（宛先・件名・見積番号・有効期限・備考・発行元入り）
  - 社内確認用に「原価・粗利つき」でも出力可（お客様に渡す版はチェックを外す）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `pricing.py` | **料金・原価データと計算ロジック（差し替えの核）**。実データはここを書き換える。 |
| `quote_excel.py` | Excel見積書の生成（openpyxl）。 |
| `intake_parse.py` | 貼り付けた問い合わせ本文の読み取り（AI／パターン照合）。 |
| `app.py` | 画面（Streamlit）。入力・積み上げ・値引き・出力。 |
| `requirements.txt` | 必要ライブラリ（streamlit, openpyxl, anthropic）。 |

## 実データへの差し替え方（本番化）

`pricing.py` の上部「料金テーブル」ブロックにある次の数値を、シール堂さんの実データに置き換えます。

- `BASE_UNIT_PRICE`（面積帯×数量帯の1枚単価マトリクス）
- `MATERIALS`（素材ごとの係数）
- `FINISH_OPTIONS` / `CUT_FORMS`（加工・仕上げの加算額）
- `DIE_CUT_FEE`（抜き型代）、`MIN_ORDER_PRICE`（最低料金）、特急割増（`LEAD_TIMES`）
- `BASE_COST_RATE` ほか原価率（社内の粗利計算に使用）

計算の流れ（`estimate` 関数）や画面はそのままで、数値だけ入れ替えれば本番の見積りになります。
